# ColabWize — Platform Overview

## What is ColabWize?
ColabWize is an academic writing integrity and collaboration platform. It helps students, researchers, and academics write better papers by verifying citations, proving authorship, detecting AI-generated content, and enabling real-time collaboration.

## Mission
A platform for original, credible, and human work.

## Core Value Proposition
- **Citation Verification** — Automatically check if citations are real, current, and not retracted
- **Authorship Certificates** — Generate PDF proof that you wrote your work (with timestamps, edit history, QR verification)
- **AI Detection** — Know if content is human-written or AI-generated
- **Real-Time Collaboration** — Work together on documents with live cursors and chat
- **Originality Checking** — Scan for plagiarism, self-plagiarism, and paraphrase detection

## Who Uses It?
- **Students** — Write papers, verify citations, prove authorship for assignments
- **Researchers** — Check citations, detect plagiarism, collaborate on papers
- **Universities** — Ensure academic integrity across departments
- **Writing Centers** — Help students improve writing quality

## Tech Stack
- Frontend: React 18, TypeScript, TailwindCSS, Tiptap editor
- Backend: Node.js v22+, Express, PostgreSQL (Prisma ORM)
- Real-time: Yjs CRDTs, Hocuspocus Server
- AI: OpenAI, Google Gemini, LangChain
- Deployment: Vercel (frontend), Render (backend)
- Database: Supabase (PostgreSQL)
