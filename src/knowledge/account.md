# ColabWize — Account & Security

## Sign Up
- Go to colabwize.com/signup
- Options: Email/Password, Google, Microsoft
- Email verification: 6-digit OTP sent via email
- Must use allowed email domain (gmail, outlook, yahoo, edu, etc.)
- Minimum age: 13 years old

## Login
- Go to colabwize.com/login
- Options: Email/Password, Google, Microsoft
- "Remember Me" keeps you signed in for 30 days
- Session refreshes automatically

## Password Requirements
- Minimum 8 characters
- At least 1 uppercase letter
- At least 1 number
- At least 1 special character (!@#$%^&*)
- Strength indicator shows password quality

## Forgot Password
1. Go to colabwize.com/forgot-password
2. Enter your email address
3. Check email for reset link (valid for 1 hour)
4. Click link and set new password
5. Sign in with new password

## Two-Factor Authentication (2FA)
**Setup:**
1. Go to Settings > Security
2. Click "Enable 2FA"
3. Scan QR code with authenticator app (Google Authenticator, Authy, etc.)
4. Enter 6-digit code to verify
5. Save recovery codes (8-character codes, use if you lose access to authenticator)

**Login with 2FA:**
1. Enter email and password
2. Open authenticator app
3. Enter 6-digit code
4. If code fails 3 times, use recovery code instead

**Disable 2FA:**
1. Go to Settings > Security
2. Click "Disable 2FA"
3. Enter current 6-digit code to confirm

## Profile Settings
**Go to:** Settings > Profile
- Update display name
- Change profile picture
- Update email (requires verification)
- Set timezone
- Language preference

## Connected Accounts
**Go to:** Settings > Connections
- Connect Google account (for OAuth login + Drive integration)
- Connect Microsoft account (for OAuth login + OneDrive integration)
- Disconnect accounts (you'll need a password set to disconnect all OAuth)

## Data & Privacy
**Go to:** Settings > Privacy
- Download your data (export all documents, activity)
- Delete account (permanently removes all data after 30-day grace period)
- Manage cookie preferences
- Opt out of marketing emails

## Security Features
- TLS 1.3 encryption in transit
- AES-256 encryption at rest
- SOC 2 Type II compliance
- Quarterly third-party penetration testing
- 24/7 security monitoring
- Role-based access control
- Automated backup and disaster recovery

## Session Management
- Sessions auto-refresh when within 5 minutes of expiry
- Sign out from all devices: Settings > Security > Sign Out All
- View active sessions: Settings > Security > Sessions
