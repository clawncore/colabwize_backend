# ColabWize — Integrations

## Academic Databases
- **CrossRef** — Real-time citation verification, DOI lookup
- **PubMed** — Biomedical literature verification
- **ArXiv** — Preprint verification
- **OpenAlex** — Semantic search, citation graph

## Reference Managers
- **Zotero** — Full integration (import/export, sync)
- **Mendeley** — Full integration (import/export, sync)
- **EndNote** — Via BibTeX/RIS import
- **Vault** — Internal research library (built-in)

## Cloud Storage
- **Google Drive** — Import documents (export not yet available)
- **Microsoft OneDrive** — Import documents

## AI Providers
- **OpenAI** — GPT models for AI features
- **Google Gemini** — Alternative AI provider
- **LangChain** — AI orchestration framework

## Email
- **Resend** — Transactional emails (OTP, verification, notifications)

## Analytics
- **Amplitude** — Product analytics
- **Google Analytics (GA4)** — Web analytics

## Security
- **Google reCAPTCHA** — Bot protection (v2 + v3)
- **Supabase Auth** — Authentication infrastructure

## Communication
- **Discord** — Webhook notifications (internal)

## Export Formats
- **PDF** — Document export, certificate generation
- **DOCX** — Microsoft Word export
- **BibTeX** — Reference export
- **RIS** — Reference export

## Not Yet Integrated
- **Google Docs** — Google Drive import exists, but no direct Google Docs editing
- **LMS** (Canvas, Blackboard, Moodle) — Not yet integrated
- **Browser Extensions** — Not available
- **Slack** — Not yet integrated
- **Overleaf** — Not yet integrated

## API Access
- REST API available for all features
- Authentication: JWT tokens
- Rate limiting applied
- Documentation: Available on request

## Webhooks
- LemonSqueezy webhooks for billing events
- Custom webhook support for enterprise customers
